# Product vision and current scope

Playai is a working name for browser party games played by a group on their phones. The room owns people, host, code, identity and evening points; games run inside it. Blindstop is the first game.

Current deliverable: a standalone clickable HTML mockup, with Blindstop and a user-approved exploratory one-round Impostor flow. No production app, accounts or live network room. Names/avatars survive local games, but browser refresh loses the local simulation. The displayed QR is not a working production join URL.

The current flow is entry -> identity -> room game selection -> Blindstop preparation -> rounds -> final -> replay preparation or game selection. See the [screen map](../games/blindstop/screens.md) and [accepted decisions](../decisions/prototype.md).

Success for this stage: a new player can understand and review the complete flow without verbal guidance, followed by the user's playtest acceptance. Production comes through separate roadmap gates.
